# MCPteam Фото — бесплатная уникализация фото без ИИ

Программа для Windows: делает из каждого фото несколько уникальных копий для объявлений (Авито, Циан, Юла),
карточек маркетплейсов и постов. Работает без интернета, оригиналы не трогает.

**Скачать:** [MCPteam-Foto.exe](https://github.com/Skeetcher111/mcpteam-foto/releases/latest) · онлайн-версия и Telegram-бот: [mcpteam.ru/foto](https://mcpteam.ru/foto/)

## Что умеет

- пакетная обработка: выбрали папку или файлы, указали число копий на фото (1–50);
- яркость, контраст, насыщенность и оттенок, резкость;
- кадр (лёгкое приближение), наклон 0,5–1,5°, зеркало;
- невидимая сетка и шум;
- EXIF: по умолчанию удаляется полностью, можно записать новый (камера, дата);
- имена файлов как с телефона (`IMG_20250314_153012.jpg`);
- ползунок силы изменений;
- каждая копия сверяется по отпечатку (dHash) с оригиналом и с другими копиями: похожие переделываются.

## Запуск из исходников

```
pip install pillow
python mcp_foto.py
python mcp_foto.py --cli папка_с_фото --out готово --copies 3   # без окна
```

Сборка exe: `pip install pyinstaller && pyinstaller --onefile --windowed --name MCPteam-Foto mcp_foto.py`
